How to get a token

Takes about two minutes on GitHub.

  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Click Generate new token, choose Only select repositories and pick the website repository.
  3. Under Repository permissions, set Contents to Read and write.
  4. Generate, copy the token, and paste it into the form.
Open GitHub token page

The token never leaves this computer except to talk to GitHub. Use Forget token on shared machines.
